# 언어 선택 대시보드 개선 계획

**Goal:** INTENT.md에 맞춰 목적 → 강점과 부담 → 비교 → 증거 순으로 언어 선택을 돕는다.

**Architecture:** 기존 정적 HTML·CSS·JS와 점수 계산을 유지한다. 선택 지원용 통계·링크 함수는 `dashboard/decision.js`, 다국어 UI는 `dashboard/decision-ui.js`로 분리한다.

**Spec:** INTENT.md와 사용자가 승인한 대시보드 리뷰 개선안(P0·P1).

## 제약

- 사전 등록 가중치·실험 판정·원자료를 바꾸지 않는다.
- 데이터가 없는 경우와 실제 0을 구분한다.
- 조건별 3회 관측과 하네스 결함을 노출한다. 품질 대리지표를 직접 품질 평가로 단정하지 않는다.
- 4개 UI 언어, 키보드 조작, 좁은 화면을 지원한다. 새 외부 라이브러리는 추가하지 않는다.

## 작업

- [x] 선택 지원 함수의 회귀 검증: 빈값·실패·모델 분리·전체 비용·증거 경로를 테스트하고 실패를 확인한다.
- [x] 통계 요약, 목적별 핵심 지표, 모델별 강점·부담, 두 언어 비교, 실험·run 증거 패널을 구현한다.
- [x] 목적 선택을 상단으로 이동하고 전체 지표표는 펼침 영역으로 옮긴다. 점과 셀을 키보드로 선택할 수 있게 한다.
- [x] 관련 JS·Python 검증과 브라우저 데스크톱·모바일 확인을 수행한다.

## 검토 초점

- 미측정·실패·실행 이탈을 숨기지 않는다. 실패의 실행 기록과 합격 조건부 요약을 분리한다.
- 두 모델의 관측값을 합쳐 한 모델의 값으로 표현하지 않는다.
- 3개 관측값의 범위를 통계적 신뢰구간으로 표현하지 않는다.
- 사전 등록 점수와 목적별 해석의 차이를 설명한다.
- 목적·모델·언어 전환 시 모든 요약과 증거 표시가 함께 바뀐다.

## 실행 기록

사용자가 리뷰 개선안의 구현을 승인했다. 현재 작업 디렉터리에서 직접 구현하며 커밋·배포는 요청 범위에 포함하지 않는다.

검증: 새 요약값이 기존 데이터의 모든 언어·모델·지표 집계와 일치한다. 증거 링크의 모든 로컬 대상이 존재한다. JavaScript 검증 2개와 Python 테스트 54개가 통과했다. Chrome에서 4개 UI 언어, 목적·모델 전환, 두 언어 비교, 범위·반복값, 전체 표·그래프에서 증거 이동을 확인했다. 390px 화면에서 페이지 폭 넘침이 없었다. 독립 리뷰에서 발견한 선택 컨트롤의 초점 소실을 수정하고 재검증했다.
